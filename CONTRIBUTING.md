# Contributing

This repository is a living reference. Responsible AI practice, tooling, and regulation change quickly, so keep it current.

## Adding or updating content

1. Identify the right file using the table in [README.md](README.md) — one topic, one file. Avoid duplicating content across sections; cross-link instead using relative markdown links.
2. Keep each file focused: a short intro, then structured sections (principles/definitions, practical guidance, examples, references).
3. When citing a regulation, standard, or tool, note the version/date where possible (e.g., "EU AI Act, as of Aug 2026") since these change over time.
4. Add new files to the relevant section's folder and update that section's index if one exists.

## Style

- Use plain Markdown, second-level (`##`) and third-level (`###`) headings for structure.
- Prefer tables for comparisons (jurisdictions, tools, techniques).
- Keep prose practical and actionable; this is a working reference, not a whitepaper.

## Review

Substantive changes to `10-regulations-and-standards/` should be reviewed by legal/compliance before merging, since this content informs real decisions.

## Versioning

Tag major content refreshes (e.g., after a new regulation takes effect) with a dated entry at the top of the relevant file: `_Last reviewed: YYYY-MM-DD_`.
